# piloproject

Статический сайт пилорамы на Nuxt 3, Vue и TypeScript. Production-сборка не содержит backend, базы данных, форм или встроенных сторонних виджетов.

## Требования и запуск

- Node.js 22.12 или новее;
- npm.

```bash
npm run setup
npm run dev
```

Сайт будет доступен по `http://127.0.0.1:3000`.

## Команды

```bash
npm run check   # проверка типов
npm run build   # статическая генерация
```

Результат генерации находится в `frontend/.output/public`.

## Архитектура и конфиденциальность

- `frontend/` — Nuxt 3 SSG;
- `deploy/` и `scripts/` — установка Nginx и атомарный деплой статики;
- `docs/` — требования, эксплуатация и зафиксированные решения.

Страница отзывов содержит только обычную ссылку на Яндекс Карты. Карта, отзывы, чаты, аналитика и рекламные пиксели не встраиваются. Предварительная заявка хранит только идентификаторы товаров и количества в localStorage браузера и ничего не отправляет на сервер.

Nginx отключает журнал обращений и оставляет только критические ошибки. Полностью исключить техническую передачу IP-адреса серверу при выдаче страницы невозможно.

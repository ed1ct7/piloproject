# Backend API

С 11 августа 2026 года backend API удалён из проекта. Сайт собирается и публикуется как статический набор файлов.

- маршрутов `/api/*` нет;
- формы отзывов, административной страницы и базы отзывов нет;
- PostgreSQL и серверные учётные данные не требуются;
- предварительная заявка работает только в браузере и не отправляет данные.

Если серверное API будет возвращено, до выпуска необходимо заново описать контракт, модель данных, правовые основания обработки и меры защиты.

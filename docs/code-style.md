# Код-стайл

## Язык

Вся документация и все комментарии в проекте пишутся **на русском языке**. Это распространяется на:

- документирующие комментарии (JSDoc, rustdoc);
- обычные строчные и блочные комментарии в коде;
- пояснительные комментарии в конфигурационных файлах (`nuxt.config.ts`, `.gitignore` и т.п.);
- файлы документации в `docs/` и `README.md`.

Исключение — идентификаторы кода (имена переменных, функций, типов, ключей API), которые остаются на английском.

Документирующие комментарии пишутся по фиксированной структуре.
Ниже — правила и эталонные примеры для TypeScript и Rust.

## TypeScript (JSDoc)

- Комментарий на русском языке.
- `@note` — дополнительное пояснение (опционально).
- `@param <имя>  <описание>` — имена параметров выравниваются в колонку (дополняются пробелами).
- `@returns <описание>` — описание возвращаемого значения.

## Rust (rustdoc)

Комментарии `///` на русском языке. Секции `#` идут в следующем порядке (при наличии):

1. Однострочное описание.
2. `# Параметры` — список `- \`имя\` - описание`.
3. `# Errors` — список `- [\`ТипОшибки\`] в случае ...`.
4. `# Возвращаемое значение` — описание результата.

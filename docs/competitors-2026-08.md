### 0.2. Структура: типовой порядок блоков у топа

1. H1 + 1–2 абзаца ввода (гео, «от производителя», «от N ₽»).
2. **Сетка товаров по сечениям с ценой** — карточки или таблица; у половины — фильтры (дерево /
   обработка / антисептик). Главный блок, он же главный источник слов.
3. Характеристики / сорта / влажность / ГОСТ (заголовок есть на 16 из 50 страниц).
4. Преимущества / почему у нас (10/50).
5. Применение — где используют (6/50).
6. Как заказать / доставка / оплата / возврат (суммарно 7–8/50).
7. Отзывы (5/50 заголовком, упоминание — на трети).
8. FAQ (10/50 по тексту, 2 — заголовком).
9. Сопутствующие / похожие товары (6/50).
10. Контакты / как нас найти + форма «Перезвоним» / «Нужен расчёт».
11. SEO-текст внизу — там, где слов не хватило выше (lenwood, alyansles, pilorama98, 78dosok).

Цифры по структуре: H2 — медиана 1–3 на страницу (у нас 4); title — медиана 74 символа,
≤65 только у 21/50 (у нас 79–87); разметка: Product 21/50, BreadcrumbList 27/50, AggregateOffer
7/50, AggregateRating 7/50, FAQPage 3/50 (у нас Product+AggregateOffer+Breadcrumb+FAQPage есть).

### 0.4. Сколько текста

- Топ-пилорамы, 50 страниц: **медиана 868 слов**, 25-й перцентиль 573, 75-й 1758. По кластерам:
  каталог 817, доска обрезная 841, сухая 899, вагонка 1122, имитация 1863, огнебиозащита 388.
- У нас: главная 284, каталог 278, лендинги 303–405 — **ниже 25-го перцентиля везде**. Оценка
  Ивана «500–700 на глаз» завышена; его «норма 1080» не подтверждается — это уровень p50–p75.
- Но текст — не единственный фактор: pilorama98/catalog (166 слов) — топ-4, pilomaterial-spb
  (350) — топ-6. Возраст, ссылки, поведенческие, карточки организаций тоже работают.
- Ориентир для нас: **600–900 видимых слов на посадочную**, набранных сеткой цен и служебными
  блоками, а не простынёй.
- По запросам «пилорама спб / ЛО» у топа 266–625 слов; там решают карточки Карт / 2ГИС / Услуг.

### 0.5. Что это меняет в правках из первого голосового

Объём и структура (сетка, калькулятор, блоки) — главное; title 45–65 и «FAQ ×5» топ не
соблюдает (делать по возможности, не в приоритете); микроразметка: **по наличию** у нас больше,
чем у большинства топа (6–8 КБ JSON-LD: LocalBusiness, Breadcrumb, ItemList→Product+AggregateOffer,
FAQPage; у pilorama98 — ноль, у 78dosok — без товаров), **по эффекту — ноль**: Яндекс не формирует
товарный сниппет из списка разных Product, нет `brand`, нет `OfferCatalog`, нет рейтинга, FAQPage
Яндекс не поддерживает. Задача — не «добавить 5 вариантов», а переделать товарную часть под формат
Яндекса. Текст под H2, FAQ на главной, порядок на /dostavka — делать как часть наполнения.

## 1. Метод и ограничения

- **Выдача**: Яндекс, регион `lr=2` (Санкт-Петербург), десктоп, 9 запросов (7 товарных +
  «пилорама спб» и «пилорама ленинградская область», добавлены по скриншоту Эдуарда), 22.08.2026
  14:00–16:30 МСК, браузер пользователя (залогинен — персонализация возможна). Каждый запрос —
  скриншот + выгрузка позиций скриптом со страницы. Реклама («Промо») и колдунщики (товарная
  галерея, «Может заинтересовать», Карты, 2ГИС, Авито, Услуги, «Быстрый ответ Алисы») исключены
  из органики. Рекламные блоки ротируются: в сессии Эдуарда по «пилорама спб» показывались
  sv-bor.ru, baza-murino.ru, рамапилорама.рф; в моей — рамапилорама.рф, 78dosok.ru,
  proizvodstvo-pilomaterialov.ru. Все три из его скриншота в анализ включены.
- **Нестабильность**: между двумя заходами на один запрос («пиломатериалы спб», интервал ~15 мин)
  состав органики менялся (напр. pilorama98.ru: позиция 7 → 6; sevles-spb.ru: 4 → 4 обе
  попытки; часть доменов появлялась/исчезала). Выдача снята один раз, не усреднена по дням.
- **Скрытые URL**: для части органических результатов Яндекс отдаёт ссылку через редирект
  `yandex.ru/search/_sttc/…`, реальный адрес в DOM отсутствует; curl на редирект → 400/405.
  Для таких результатов: (а) 7 страниц восстановлены по точному совпадению `<title>` с заголовком
  в выдаче (помечены `resolved-1`), (б) остальные — взята категория с сайта конкурента по теме
  запроса (помечены `category (serp url hidden)`). Это не обязательно та самая страница, что
  ранжируется.
- **Страницы**: 81 URL (7 наших + 74 конкурентов), скачаны одиночными запросами с паузой 1 с,
  UA Chrome. `spb.lemanapro.ru` (Леруа) — 3 страницы **BLOCKED** (401 / обрыв соединения),
  `pilomat-pro.ru` — **403**; в метриках отсутствуют. `pilomaterialyvspb.ru` — cp1251, перечитан
  с правильной кодировкой.
- **Слова** — видимый текст всей страницы (шапка, меню, футер включены). Метод одинаковый для
  наших и чужих страниц, поэтому сравнение честное, но абсолютные числа завышены относительно
  «полезного текста» (у сайтов с большим меню — сильнее).
- **Гипермаркеты** (petrovich.ru, lemanapro, vseinstrumenti, grandline, finlux) вынесены отдельно:
  другой тип сайта, их структура нам не ориентир.

   2ГИС, Услуги, 78dosok, sv-bor). Из сайтов — pilorama98.ru и 78dosok.ru (по q9 — их страницы
   **контактов**), дальше мелкие пилорамы: pilorama.spb.ru, terrafox.ru, lpmspb.ru («Пилорама
   Виллози», Ломоносовский район — ещё один прямой гео-конкурент), sv-bor.ru, piloramaspb.ru,
   пилорама.com. Текст у них 266–625 слов (terrafox — 1447), title 48–102; FAQ у 1 из 9,
   калькулятор у 1, отзывы у 3, разметка LocalBusiness/Organization у 3. Для этих запросов
   решают карточки организаций и гео-сигналы, не объём текста.
2. **Реклама занимает первый экран**: 6–11 промо-блоков на запрос (включая товарную галерею).
   Органика начинается ниже первого экрана. tdlesovik, sofbaz, рамапилорама, kronawood,
   virastroy24 покупают Директ по большинству наших запросов (tdlesovik — в 5 из 7 товарных).
3. **Объём текста у топа**: медиана 868 слов на страницу, межквартильный размах 573–1758
   (n=50 страниц конкурентов-«пилорам»). **Наши посадочные 303–405 слов, главная 284,
   каталог 278 — ниже 25-го перцентиля в каждом кластере.** При этом разброс огромный:
   pilorama98.ru/catalog — 166 слов и 4-е место; kraskidoski.ru — 5 000+ слов SEO-простыни.
   Норма «минимум 1080 слов» не подтверждается; рабочий ориентир для нас — 600–900 видимых слов
   на посадочную.
4. **Откуда у топа слова**: не из статей, а из **сетки размеров с ценами**. pilorama98.ru —
   16 позиций «Доска обрезная 25×100×6000 мм … цена» отдельными H3; 78dosok.ru — 14+ размеров
   отдельными H2 на категорию; sevles-spb.ru — 76 товарных ссылок в меню. У нас — 1–4 агрегированные
   карточки «от N ₽/м³». Это главный структурный разрыв: и объём, и long-tail («доска 50х150х6000
   цена спб»), и поведенческий фактор (посетитель видит свой размер).
5. **Title**: медиана у топа 74 символа; ≤65 символов только у 21 из 50 страниц. Топ «норму

6. **FAQ**: блок вопросов есть на 10 из 50 страниц конкурентов, разметка FAQPage — на 3.

7. **H2**: медиана у топа 1–3 на страницу (у нас 4). Структура топа не «больше заголовков»,

## 5. Что делать (по приоритету)

1. **Сетка размеров с ценой на каждой посадочной** (таблица: сечение × длина × сорт → ₽/м³ и
   ₽/шт). В прайсе (`utils/products.ts`) 13 позиций по сортам с ценой за м³, без сечений —
   цена за штуку считается арифметически (объём доски × цена м³). Нужно у владельца: список
   ходовых сечений и подтверждение, что цена за м³ не зависит от сечения. Даёт +200–400 слов
   релевантного текста на страницу, long-tail, таблицу (как у половины топа).
2. **Калькулятор кубатуры** (сечение × длина × количество ↔ м³ ↔ ₽) — есть у 60–70 % топа, без
   бэкенда, одна Vue-компонента. Ставится на каталог и посадочные.
3. **Служебные блоки на посадочных**: «Как заказать» (3 шага), «Доставка и самовывоз» (2–3 строки
   + ссылка на /dostavka), «Почему у нас» (производитель, Ломоносовский район, свой транспорт),
   гео-абзац (Разбегаево, Ломоносовский р-н, Красное Село, Петергоф, Стрельна, Гатчина — по
   радиусу доставки). Закрывает пункты 1, 3, 5 Ивана и поднимает объём до ориентира.
4. **Гео-страницы** по примеру 78dosok.ru — 3–5 страниц «Пиломатериалы в <Ломоносовский район /
   Красное Село / Петергоф / Гатчина / Кингисепп>» с уникальным текстом и ценами. Риск дублей —
   только при шаблонном тексте; делать по одной, смотреть Вебмастер.
5. **Карточки организаций под запросы «пилорама …»**: довести карточку Яндекс Карт (модерация
   с 18.08), завести 2ГИС и Яндекс Услуги (оба в топ-5 по q8/q9 и в источниках «Быстрого ответа
   Алисы»), собрать первые отзывы. Для брендово-гео запросов это весомее текста.
6. **Страница контактов как посадочная** (по образцу 78dosok.ru/contacts/): адрес с ориентирами,
   как проехать из СПб / по Ломоносовскому району, режим, реквизиты, самовывоз, ссылка на карточку
   Карт и отзывы — с 175 до ~500 слов.
7. **Отзывы + AggregateRating** — после появления отзывов на карточке Карт: блок цитат со
   ссылкой.
8. **Мелочи из фидбэка**: title ~60–70 символов, порядок блоков на /dostavka, FAQ до 4–5 там, где
   есть что спросить.

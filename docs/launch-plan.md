# План запуска сайта

Пошаговый план вывода сайта в продакшен и в поиск Яндекса. Техническая база и
SEO-требования — в [yandex-seo.md](yandex-seo.md), процедура деплоя — в
[deployment.md](deployment.md), передача активов владельцу — в [handover.md](handover.md).

## Стратегия

- Сайт запускается **на собственном домене, отдельно** от визитки Яндекс Бизнеса
  (`pilorama-razbegaevo.clients.site`). Визитка остаётся жить параллельно — переезд
  с неё невозможен (301 на clients.site не настроить), а по справке Яндекса визитка
  и свой сайт не конкурируют. Подробности и аффилиат-риски — [yandex-seo.md](yandex-seo.md) §10.
- Хостинг — VPS в РФ: география сервера на ранжирование не влияет, но решают аптайм,
  доступность из РФ и TTFB до аудитории СПб/ЛО ([yandex-seo.md](yandex-seo.md) §11).
  Домашний ПК с туннелем — только для тестовых стендов и только с `X-Robots-Tag: noindex`.

## На кого оформлять

Принцип: всё, что накапливает ценность — на бизнес; исполнитель — только руки.

| Актив | На кого |
|-------|---------|
| Домен | владелец (ИП/ООО или физлицо) |
| VPS | аккаунт владельца, исполнителю — доп-доступ/SSH |
| Вебмастер, Метрика | Яндекс ID бизнеса, исполнителю — делегированные права |
| Карточка Яндекс Бизнеса | уже у владельца |

### Запуск без владельца

Если владелец недоступен, запуск не блокируется — оформить на исполнителя всё,
что легко передать (процедуры передачи — [handover.md](handover.md)):

- **VPS, Вебмастер, Метрика** — на себя, передача тривиальна.
- **Домен** — на себя как физлицо; смена администратора у регистратора потом —
  стандартная процедура.
- **Ждёт владельца только карточка Яндекс Бизнеса** (поле «Сайт» → новый домен).
  Без этого локальная выдача (блок Карт) ведёт на визитку, но органика сайта
  работает независимо.
- **Не заводить новую карточку организации со своего аккаунта** — будет дубль
  организации на Картах, склеивать потом мучительно.

## Покупки

- **Домен `.ru`** — REG.RU / Timeweb / Beget, ~300–700 ₽/год. Короткий, читаемый.
- **VPS** — Timeweb Cloud (просто передавать и админить) или Selectel (ДЦ СПб,
  закрывающие документы для юрлица). Тариф: 2 vCPU, 2 ГБ RAM, 30 ГБ NVMe,
  ~400–700 ₽/мес — достаточно с запасом.
- **Корпоративная почта на домене — для SEO не нужна.** Не фактор ранжирования,
  ничего не блокирует; подключается в любой момент позже (Яндекс 360) — это про
  солидность переписки, не про позиции.

## Чеклист запуска

### Код (перед сборкой)

1. `frontend/utils/seo-routes.ts` → `siteUrl` = новый домен (единственный источник:
   canonical, sitemap, robots, schema, CSP подтянутся сами).
2. `ALLOWED_ORIGINS` backend → новый домен.
3. `NUXT_PUBLIC_API_BASE=<домен> npm run generate` — **backend должен быть запущен
   и доступен в момент сборки**: отзывы запекаются в статический HTML.

### Сервер

4. Деплой по [deployment.md](deployment.md): PostgreSQL, backend под systemd,
   статика, реверс-прокси с HTTPS.
5. Зеркала **до первой индексации** ([yandex-seo.md](yandex-seo.md) §10):
   301 `http → https`, `www → без-www` (или наоборот, но один вариант),
   слэш-дубли на один вариант.

### Поисковые сервисы (день запуска)

6. **Вебмастер**: добавить главное зеркало, подтвердить права, залить sitemap,
   задать регион СПб + ЛО («Информация о сайте → Региональность»), отправить
   ключевые страницы в «Переобход страниц».
7. **Метрика**: поставить счётчик (асинхронно), в Вебмастере включить
   «Обход по счётчикам».
8. **Яндекс Бизнес** (когда доступен владелец): поле «Сайт» → новый домен.
   Визитку не трогать.
9. Опционально: IndexNow — ключ-файл в `frontend/public/`, пинг API после деплоя
   ([yandex-seo.md](yandex-seo.md) §7).

### Контент после запуска (даёт позиции — [yandex-seo.md](yandex-seo.md) §9)

10. **Цены на страницы** — главный недостающий коммерческий фактор.
11. Реквизиты (ИНН/ОГРН) в футер / страница «О компании».
12. Телефон на все страницы + `telephone` в LocalBusiness-разметку.
13. Уникальные тексты — не копировать с визитки (аффилиат-риск, §10).
14. Постепенно: страницы под кластеры запросов (Wordstat), геолендинги (§4),
    ответы на отзывы в карточке Бизнеса.

## Сроки и контроль

- Страницы в индексе: дни – 3 недели (с переобходом/IndexNow — быстрее).
- Регион присвоен, позиции устаканились: 1–3 месяца, по конкурентным
  коммерческим запросам дольше.
- Ритм: раз в неделю Вебмастер (обход, ошибки, запросы, ИКС) и Метрика
  (отказы, источники, конверсии). Процесс итеративный: смотреть → править → ждать.
- У поиска нет «песочницы»: любой индексируемый домен — боевой. Что проверяется
  локально, а что только на проде — [yandex-seo.md](yandex-seo.md) §12.

# План запуска

## До публикации

- подтвердить адрес владельца сайта и продавца для обращений и корреспонденции;
- проверить карточку организации в Яндекс Картах и права владельца;
- указать регистрирующий орган (ИНН и ОГРНИП уже опубликованы в реквизитах на сайте);
- проверить публичный email `shidov_roman@mail.ru`;
- выполнить `npm run check` и `npm --prefix frontend run generate`;
- проверить все страницы, телефоны, email, sitemap и robots.txt;
- проверить, что в браузере до клика нет запросов к сторонним доменам.

## После публикации

- добавить сайт в Яндекс Вебмастер и следить за индексированием;
- поддерживать цены, наличие и реквизиты в актуальном состоянии;
- не подключать Метрику, рекламные пиксели, формы, чаты и виджеты без отдельного согласования режима обработки данных.

Платную рекламу можно вести без Метрики, но возможности измерения конверсий и автоматической оптимизации будут ограничены.

# Обновление цен и позиций

Пошаговая инструкция для правки прайса без знания проекта.

## Где лежат данные

1. **Прайс-лист** — `frontend/utils/products.ts`, массив `priceListProducts`.
   Поле `price` — число без пробелов (`18000`), `price: null` — «цена по запросу».
   `pricePrefix: 'от'` выводит цену как минимальную.
2. **Посадочные SEO-страницы** — `frontend/utils/seo-landings.ts`. Цены здесь
   продублированы текстом в `title`, `metaDescription`, `intro`, `details` и `faq`.
   **При каждом изменении прайса сверять вручную** — автоматической синхронизации нет.
3. Контакты и реквизиты — `frontend/utils/business.ts`.

## Порядок действий

```bash
# 1. Правки в файлах выше, затем проверки:
npm run check                       # типы
npm --prefix frontend run test:unit # юнит-тесты
npm --prefix frontend run generate  # сборка статики

# 2. Коммит и пуш в main.

# 3. Деплой — команда из docs/deploy-command.md (на сервере от root).
```

## После деплоя

- Проверить изменённые страницы на сайте (цены, тексты).
- В Яндекс Вебмастере отправить изменённые страницы на переобход
  (Индексирование → Переобход страниц) — иначе сниппеты с ценами
  обновятся только после планового обхода.

## Чего не делать

- Не менять слаги страниц (`/doska`, `/vagonka`, …) — потеря позиций в поиске.
- Не добавлять счётчики и внешние скрипты: деплой упадёт на privacy-guard
  (`scripts/deploy-production.sh`), это осознанное решение владельца.
- Не менять `title`/`h1` без необходимости — каждая смена вызывает
  переранжирование в Яндексе на недели.
